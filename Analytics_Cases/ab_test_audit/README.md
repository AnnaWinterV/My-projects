# 📊 Аудит A/B-тестирования

**Цель проекта:** Проверка корректности проведенного A/B-теста и анализ его результатов для стратегических решений.

---

## 🎯 Задачи
- Оценка валидности A/B-теста  
- Выявление возможности использования результатов теста для создания стратегии

---

## 🧰 Стек технологий
Python • Pandas • Matplotlib • Yandex DataLens

---

## 📈 Результаты
- Выявлены ошибки в проведении теста, предотвращающие ошибочные решения  
- Опровергнута гипотеза о значимости различий между группами  
- Сформированы рекомендации по корректному проведению будущих A/B-тестов
