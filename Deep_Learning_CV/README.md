# 🔬 R&D и Computer Vision

В этом разделе собраны прикладные проекты по компьютерному зрению и генеративным моделям: от классификации и детекции объектов до работы с латентными пространствами нейросетей.

---

### 1. [Классификация персонажей «Симпсонов»](./simpsons_classification/)
**Задача:** Построить качественную модель классификации изображений на основе Transfer Learning.  
**Стек:** Python, PyTorch, Pandas, Matplotlib, ResNet18.  
**Результат:**
- Проанализирован датасет с 42 классами персонажей, внедрена расширенная аугментация данных.
- Добились **F1-score = 0.99256** на платформе Kaggle (*Journey to Springfield*).

---

### 2. [Детекция автотранспорта на аэрофотоснимках (БПЛА)](./vehicle_detection/)
**Задача:** Обучить модель детекции для поиска транспорта с дронов и упаковать её в готовый MVP-сервис.  
**Стек:** Python, Ultralytics (YOLO11m), FastAPI, Streamlit, OpenCV.  
**Результат:**
- Подготовлен датасет VisDrone (выделено 7 классов транспорта), обучена модель YOLO11m с повышенным разрешением входа (`imgsz=960`) для точного поиска мелких объектов.
- Создано и задеплоено модульное веб-приложение:
  - 🌐 [Живое демо на Streamlit](https://drone-detector.streamlit.app/)
  - 📊 [Презентация проекта (Google Drive)](https://drive.google.com/file/d/1nmS44q0gA_qWZAeCNFwawcpCUOHyju1A/view?usp=sharing)

### 3. [Исследование архитектур автоэнкодеров (VAE, CVAE, Denoising)](./autoencoders/)
**Задача:** Реализовать и сравнить архитектуры автоэнкодеров «с нуля» для задач поиска и модификации изображений.  
**Стек:** Python, PyTorch, scikit-learn (t-SNE, LDA, NearestNeighbors), LFW Dataset, MNIST.  
**Результат:**
- Реализован механизм вычисления «вектора улыбки» и успешное разделение «стиля» и «содержания» в CVAE (точность LDA выросла до 0.960 против 0.915 в Vanilla VAE).
- Построен прототип системы семантического поиска лиц (Image Retrieval) с помощью k-NN в латентном пространстве.

---

### 4. [Текстовое редактирование лиц (StyleGAN2 + CLIP)](./face_editor/)
**Задача:** Настроить систему семантического редактирования изображений с помощью текстовых промптов без дообучения генератора.  
**Стек:** Python, PyTorch, StyleGAN2, CLIP (OpenAI), NumPy.  
**Результат:**
- Реализована оптимизация латентного пространства (W-space) StyleGAN2 по градиентам функции потерь CLIP.
- Реализована возможность zero-shot изменения атрибутов лица (возраст, улыбка, прическа) с помощью текстовых запросов.
