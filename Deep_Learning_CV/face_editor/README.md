# 🎭 Текстовое редактирование лиц (StyleGAN2 + CLIP)

**Цель проекта:** Создание системы для семантического редактирования лиц на изображениях с помощью текстовых описаний (text-driven image manipulation) без необходимости дообучения генеративной модели с нуля.

### 🎯 Задачи
- Интегрировать две предобученные SOTA-модели: генеративную (StyleGAN2) и мультимодальную (CLIP).
- Реализовать механизм оптимизации латентного пространства (W-space) для изменения атрибутов лица на основе текстового промпта.
- Написать эффективный интеграционный код ("клей") для совместной работы моделей в среде PyTorch.

### 🧰 Стек технологий
Python • PyTorch • StyleGAN2 (NVIDIA) • CLIP (OpenAI) • NumPy • Matplotlib

### 🔬 Методология и архитектура
В данной работе мы не обучаем нейросети с нуля, а используем их предобученные веса, что является стандартом для эффективного прототипирования:

1. **StyleGAN2 (Generator):** Используется предобученная модель на датасете FFHQ (512x512). Она отвечает за генерацию фотореалистичных лиц. Мы работаем не с пикселями, а с латентным вектором `W` (W-space), который управляет семантическими признаками изображения.
2. **CLIP (Vision-Language Model):** Используется модель `ViT-B/32` для оценки семантического соответствия. Она выступает в роли "функции потерь" (loss function), направляя оптимизацию латентного вектора в сторону, описанную текстовым запросом.
3. **Процесс оптимизации:** 
   - Берется исходный латентный код изображения.
   - На каждой итерации генерируется изображение, которое кодируется через CLIP.
   - Вычисляется косинусное расстояние между эмбеддингом изображения и эмбеддингом целевого текстового промпта.
   - С помощью градиентного спуска (optimizer) латентный код обновляется так, чтобы минимизировать эту разницу, сохраняя при этом общую идентичность лица.

### 🚀 Результаты
- Реализован рабочий пайплайн, позволяющий изменять атрибуты лица (например, добавить улыбку, изменить прическу, возраст или выражение лица) с помощью простых текстовых команд (например, *"a person with a big smile"* или *"an older person"*).
- Продемонстрировано понимание работы латентных пространств генеративных моделей и методов zero-shot манипуляции изображениями.
- Код структурирован для удобного запуска в среде Google Colab с поддержкой GPU.

### 💡 Ключевые инсайты
- Работа в W-space (а не в Z-space) StyleGAN2 обеспечивает гораздо более плавные и семантически осмысленные изменения без артефактов.
- Балансировка веса CLIP loss критически важна: слишком высокий вес приводит к разрушению структуры лица (artifacts), слишком низкий — к незаметным изменениям.
- Использование предобученных моделей позволяет создавать мощные инструменты редактирования с минимальными вычислительными затратами по сравнению с полным fine-tuning.
