# 🎭 Классификация персонажей "Симпсонов" с помощью глубокого обучения

**Цель проекта:** Создание точной модели для автоматического распознавания и классификации 42 персонажей мультсериала "Симпсоны" на изображениях в рамках соревнования [Journey to Springfield](https://www.kaggle.com/competitions/journey-to-springfield1).

### 🏆 Результаты
- **Kaggle Score:** **0.99256** (F1-score) — топ-165 из 2000+ участников
- **Локальная валидация:** F1 = 0.9758
- **Прогресс:** Улучшение с 0.922 → 0.99256 за счет transfer learning

### 🎯 Задачи
- Реализовать модель классификации изображений на основе transfer learning
- Провести сравнение эффективности архитектур нейронных сетей (Simple CNN vs ResNet18)
- Выполнить детальный анализ ошибок модели и проблем датасета
- Достичь максимальной точности распознавания персонажей

###  Стек технологий
Python • PyTorch • ResNet18 • Transfer Learning • Fine-tuning • Data Augmentation • sklearn • Pandas • Matplotlib

### 📊 Данные
- **Датасет:** [Journey to Springfield (Kaggle)](https://www.kaggle.com/competitions/journey-to-springfield1/data)
- **Объем:** 20,933 обучающих изображения, 991 тестовое изображение
- **Классы:** 42 персонажа (Homer, Marge, Bart, Lisa, Mr. Burns и др.)
- **Проблема:** Критический дисбаланс классов и 1,454 файла-дубликата (20,141 пересечение)

### 🔬 Этапы работы

**1. Базовая модель (Simple CNN):**
- Собственная сверточная сеть с ранней остановкой (early stopping)
- Результат: F1 = 0.80 (валидация), 0.922 (Kaggle)
- *Вывод:* Недостаточно для соревновательного уровня

**2. Transfer Learning (ResNet18):**
- Загрузка предобученной ResNet18 с заменой последнего слоя на 42 класса
- Fine-tuning всех слоев модели
- Расширенная аугментация: RandomHorizontalFlip, RandomRotation (10°), ColorJitter
- Результат: F1 = 0.9738 (валидация), **0.99256 (Kaggle)** 

**3. Оптимизация и анализ:**
- AdamW с L2-регуляризацией и CosineAnnealing scheduler
- Разные learning rate для разных слоев
- Анализ confusion matrix и самых частых ошибок
- *Инсайт:* Самые частые ошибки — Abraham → Homer (6 раз), Edna Krabappel → Nelson Muntz (3 раза)

**4. Работа с дубликатами:**
- Обнаружено 1,454 файлов, встречающихся в нескольких классах
- *Парадокс:* Агрессивная очистка данных привела к падению accuracy с 1.0 → 0.06
- *Решение:* Сохранение дубликатов как естественной части датасета

### 💡 Ключевые инсайты
- **Transfer learning** с ResNet18 дал скачок качества на **7%** (0.922 → 0.99256)
- **Простые модели** с грамотной настройкой превзошли сложные эксперименты
- **Аугментация данных** критически важна при дисбалансе классов
- **Анализ ошибок** помог понять специфику датасета (похожие персонажи, дубликаты)
