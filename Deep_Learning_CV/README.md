Предлагаю Вашему вниманию мои проекты для ознакомления. Здесь собраны работы, связанные с классификацией, детекцией и генерацией изображений, от изучения фундаментальных архитектур до создания полноценных веб-приложений (MVP).

## Проект №1: Классификация персонажей "Симпсонов" 

**Задачи:**
- Построение модели классификации изображений персонажей мультсериала "Симпсоны"
- Применение transfer learning и fine-tuning для улучшения точности
- Анализ качества классификации, дубликатов в данных и визуализация результатов

**Стек:**
Python, PyTorch, Pandas, Matplotlib, Transfer Learning (ResNet18)

**Результат:**
- Проанализирован датасет с изображениями основных персонажей (42 класса)
- Реализована модель на основе ResNet18 с transfer learning и fine-tuning
- Применена расширенная аугментация данных для улучшения обобщающей способности
- **Достигнута точность (F1-score) 0.99256 на платформе Kaggle** (соревнование Journey to Springfield)

## Проект №2: Детекция автотранспорта на аэрофотоснимках (БПЛА)

**Задачи:**

## Проект №3: Исследование архитектур автоэнкодеров (VAE, CVAE, Denoising)

**Задачи:**
- Реализация и сравнение Vanilla AE, VAE и Conditional VAE "с нуля" на PyTorch
- Эксперименты с арифметикой латентного пространства и удалением шума
- Создание прототипа системы семантического поиска изображений (Image Retrieval)

**Стек:**
Python, PyTorch, scikit-learn (t-SNE, LDA, NearestNeighbors), LFW Dataset, MNIST

**Результат:**
- Реализован механизм вычисления "вектора улыбки" для изменения выражения лица через латентное пространство
- Обучен CVAE, который успешно разделяет "стиль" и "содержание" (LDA accuracy выросла с 0.915 до 0.960 по сравнению с обычным VAE)
- Создан рабочий прототип поиска похожих лиц по изображению с помощью k-NN в латентном пространстве

## Проект №4: Текстовое редактирование лиц (StyleGAN2 + CLIP)

**Задачи:**
- Создание системы для семантического редактирования лиц на изображениях с помощью текстовых описаний
- Интеграция предобученных SOTA-моделей без необходимости обучения с нуля

**Стек:**
Python, PyTorch, StyleGAN2 (NVIDIA), CLIP (OpenAI), NumPy

**Результат:**
- Реализован механизм оптимизации латентного пространства (W-space) StyleGAN2 на основе градиентов функции потерь CLIP
- Достигнута возможность редактирования атрибутов лица (прическа, улыбка, возраст) с помощью текстовых промптов
- Продемонстрировано понимание работы латентных пространств генеративных моделей и методов zero-shot манипуляции
