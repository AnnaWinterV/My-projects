## Проект №1: Классификация персонажей "Симпсонов" 

**Задачи:**
- Построение модели классификации изображений персонажей мультсериала "Симпсоны"
- Применение transfer learning и fine-tuning для улучшения точности
- Анализ качества классификации, дубликатов в данных и визуализация результатов

**Стек:**
Python, PyTorch, Pandas, Matplotlib, Transfer Learning (ResNet18)

**Результат:**
- Проанализирован датасет с изображениями основных персонажей (42 класса)
- Реализована модель на основе ResNet18 с transfer learning и fine-tuning
- Применена расширенная аугментация данных для улучшения обобщающей способности
- **Достигнута точность (F1-score) 0.99256 на платформе Kaggle** (соревнование Journey to Springfield)
- Модель демонстрирует высокую эффективность для распознавания мультперсонажей

## Проект №2: Детекция автотранспорта на аэрофотоснимках (БПЛА)

**Задачи:**
- Обучение модели компьютерного зрения для поиска транспорта на снимках с дронов
- Создание backend-ядра (API) и веб-интерфейса для демонстрации работы модели
- Деплой готового ML-приложения (MVP) в облако

**Стек:**
Python, Ultralytics (YOLO11m), FastAPI, Streamlit, OpenCV

**Результат:**
- Подготовлен и конвертирован датасет VisDrone (выделено 7 классов: car, van, truck, bus и др.)
- Обучена модель YOLO11m с увеличенным разрешением входа (`imgsz=960`) для эффективной детекции мелких объектов
- Реализовано модульное веб-приложение: интерфейс на Streamlit + API на FastAPI
- Приложение успешно задеплоено: 
  - 🌐 [Живое демо на Streamlit](https://drone-detector.streamlit.app/) *(требуется ~30 сек на холодный старт)*
  - 📊 [Презентация работы приложения (Google Drive)](https://drive.google.com/file/d/1nmS44q0gA_qWZAeCNFwawcpCUOHyju1A/view?usp=sharing)
