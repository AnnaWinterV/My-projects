# 🧠 Исследование архитектур автоэнкодеров (VAE, CVAE, Denoising)

**Цель проекта:** Глубокое изучение и практическая реализация различных архитектур автоэнкодеров для решения задач сжатия, генерации, удаления шума и семантического поиска изображений "с нуля" на PyTorch.

### 🎯 Задачи
- Реализовать Vanilla Autoencoder для сжатия лиц (датасет LFW) и экспериментировать с арифметикой латентных векторов.
- Обучить Variational Autoencoder (VAE) и Conditional VAE (CVAE) на датасете MNIST для изучения баланса между реконструкцией и генерацией.
- Применить Denoising Autoencoder для восстановления зашумленных изображений.
- Создать прототип системы поиска похожих лиц (Image Retrieval) на основе латентных представлений.

### 🧰 Стек технологий
Python • PyTorch • scikit-learn (t-SNE, LDA, NearestNeighbors) • LFW Dataset • MNIST Dataset

### 🔬 Реализованные архитектуры и эксперименты

**1. Vanilla Autoencoder (LFW Faces):**
- Архитектура: CNN-энкодер (сжатие до 64D) + CNN-декодер.
- *Эксперимент:* Вычислен "вектор улыбки" как разность средних латентных кодов улыбающихся и грустных лиц. Добавление этого вектора к латентному коду меняет выражение лица при декодировании.

**2. Variational Autoencoder (VAE, MNIST):**
- Введение KL-дивергенции в функцию потерь для регуляризации латентного пространства (приведение к нормальному распределению $N(0,1)$).
- *Результат:* Демонстрация классического trade-off VAE: слегка размытая, но стабильная генерация новых цифр.

**3. Conditional VAE (CVAE, MNIST):**
- Модификация VAE с передачей one-hot вектора класса на вход энкодера и декодера.
- *Результат:* Разделение "стиля" (латентный вектор $z$) и "содержания" (класс). Возможность генерировать цифры заданного класса с сохранением единого стиля начертания. LDA accuracy выросла с 0.915 (VAE) до 0.960 (CVAE).

**4. Denoising Autoencoder (LFW Faces):**
- Обучение модели реконструировать чистое изображение из зашумленного входа (Gaussian noise, factor=0.3).
- *Результат:* Эффективное удаление шума и восстановление базовой структуры лица.

**5. Image Retrieval (Поиск по лицу):**
- Использование латентных представлений VAE в качестве эмбеддингов.
- Построение индекса с помощью `NearestNeighbors` (Ball Tree) для мгновенного поиска визуально похожих лиц в базе по запросу с "камеры наблюдения".

### 💡 Ключевые инсайты
- **Арифметика латентного пространства работает:** Даже простой AE способен выучить семантические направления (например, "улыбка").
- **Преимущество CVAE:** Анализ через t-SNE показал, что CVAE успешно выносит информацию о классе из латентного пространства в веса декодера, делая само латентное пространство более "чистым" и пригодным для downstream-задач.
- **Универсальность признаков:** Модель поиска лиц показала работоспособность, доказывая, что автоэнкодеры выучивают общие визуальные паттерны, а не просто запоминают пиксели.
