## Проект №1: Классификация персонажей "Симпсонов" 

**Задачи:**
- Построение модели классификации изображений персонажей мультсериала "Симпсоны"
- Применение transfer learning и fine-tuning для улучшения точности
- Анализ качества классификации и визуализация результатов

**Стек:**
Python, PyTorch, Pandas, Matplotlib, Transfer Learning (ResNet)

**Результат:**
- Проанализирован датасет с изображениями основных персонажей Симпсонов
- Реализована модель на основе ResNet18 с transfer learning и fine-tuning
- **Достигнута точность 0.99256 на платформе Kaggle**
- Применена аугментация данных для улучшения обобщающей способности
- Проведен анализ дубликатов и качества данных
- Модель демонстрирует эффективность для распознавания мультперсонажей
