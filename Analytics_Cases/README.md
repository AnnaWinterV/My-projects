# 📊 Аналитические кейсы и исследования

В этом разделе собраны прикладные проекты по продуктовой и товарной аналитике, A/B-тестированию и построению скоринговых моделей.

---

### 1. [Аудит A/B-тестирования](./ab_test_audit/)
**Задача:** Проверить корректность проведения A/B-теста и оценить целесообразность раскатки изменений в продакшн.  
**Стек:** Python (Pandas, SciPy, Matplotlib), Yandex DataLens.  
**Результат:**
- Проведен аудит дизайна эксперимента и проверка корректности сплитования трафика (A/A-тестирование).
- Статистически опровергнута значимость различий между тестовой и контрольной группами, что защитило бизнес от раскатки неэффективного решения.
- Подготовлен чек-лист рекомендаций по дизайну и валидации будущих экспериментов.

---

### 2. [Оптимизация товарного ассортимента](./product_assortment/)
**Задача:** Выявить драйверы выручки, неликвидные позиции и сформировать рекомендации по управлению товарной матрицей.  
**Стек:** SQL, Python (Pandas, NumPy, Seaborn, Matplotlib), Yandex DataLens.  
**Результат:**
- Выполнена агрегация и очистка сырых транзакционных данных с помощью SQL и Python.
- Проведена сегментация ассортимента (ABC/XYZ-анализ), выделены ключевые категории, формирующие основную маржу, и кандидаты на вывод из матрицы.
- Собран интерактивный дашборд в **Yandex DataLens** для мониторинга оборачиваемости и динамики продаж.

---

### 3. [Прогнозирование оттока клиентов (Телеком)](./telecom_churn/)
**Задача:** Построить модель скоринга оттока и выделить ключевые триггеры ухода пользователей для отдела удержания.  
**Стек:** Python (Pandas, Scikit-learn, CatBoost, Optuna, Matplotlib).  
**Результат:**
- Проведен разведочный анализ (EDA), обработка категориальных признаков и генерация новых фичей (Feature Engineering).
- Проведено сравнение алгоритмов (Logistic Regression vs CatBoost) с подбором гиперпараметров через Optuna; итоговое качество на тесте составило **ROC-AUC = 0.851**.
- Выделены топ-5 факторов оттока (`MonthlySpending`, `ClientPeriod`, `NumServices`, `HasFamily`, `ServiceDensity`), на базе которых сформированы рекомендации для целевых кампаний удержания.

### 4. [Поведенческая сегментация клиентов](./customer_segmentation/)
**Задача:** Сегментировать клиентскую базу на основе транзакционной активности для персонализации маркетинговых коммуникаций.  
**Стек:** Python (Pandas, NumPy, Matplotlib, Seaborn).  
**Результат:**
- Проведен кластерный и когортный анализ поведения пользователей, выделены устойчивые клиентские сегменты.
- Сформированы продуктовые и маркетинговые гипотезы по повышению LTV и частоты покупок для каждого сегмента.

### 5. [Анализ факторов оттока клиентов банка](./bank_churn_analysis/)
**Задача:** Определить профиль клиента, склонного к закрытию счетов, и оценить влияние продуктовых метрик на лояльность.  
**Стек:** Python (Pandas, Matplotlib), Yandex DataLens.  
**Результат:**
- Проведен сравнительный статистический анализ ушедших и лояльных клиентов по социально-демографическим и транзакционным признакам.
- Визуализированы ключевые точки падения удержания и подготовлены рекомендации по доработке программы лояльности.
