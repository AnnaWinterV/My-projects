# 🛒 Стратегическая оптимизация товарного ассортимента

**Цель проекта:** Анализ и оптимизация товарного ассортимента для увеличения прибыли и эффективности продаж.

---

## 🎯 Задачи
- Анализ ассортимента и выявление ключевых товаров  
- Формирование и проверка гипотез для оптимизации матрицы  
- Создание наглядных дашбордов для контроля

---

## 🧰 Стек технологий
Python • Pandas • NumPy • Seaborn • Matplotlib • SQL • Yandex DataLens

---

## 📈 Результаты
- Преобразованы сырые данные в структурированные  
- Выделены наиболее прибыльные позиции ассортимента  
- Созданы визуализации и дашборды для мониторинга результатов
