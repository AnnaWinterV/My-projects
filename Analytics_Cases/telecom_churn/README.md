# 📞 Прогноз оттока клиентов телеком-компании

**Цель проекта:** Построение модели прогнозирования оттока клиентов и выявление факторов, влияющих на уход.

---

## 🎯 Задачи
- Предобработка данных (категориальные и числовые признаки)  
- Построение моделей прогнозирования: логистическая регрессия, CatBoost  
- Оптимизация модели для повышения точности  
- Определение ключевых признаков оттока

---

## 🧰 Стек технологий
Python • Pandas • Scikit-learn • CatBoost • Optuna • Matplotlib

---

## 📈 Результаты
- Лучший ROC-AUC на тесте = 0.851 (CatBoost с оптимизированными параметрами)  
- Ключевые признаки оттока: MonthlySpending, ClientPeriod, NumServices, HasFamily, ServiceDensity  
- Модель готова для практического применения в стратегии удержания клиентов
