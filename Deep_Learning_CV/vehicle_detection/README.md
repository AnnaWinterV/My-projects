# 🚁 Детекция автотранспорта на аэрофотоснимках (Deep Learning MVP)

**Цель проекта:** Создание полноценного ML-приложения (MVP) для автоматического поиска и детекции транспортных средств на аэрофотоснимках с БПЛА. Проект реализован в роли ML Engineer: от самостоятельного выбора архитектуры и подготовки данных до деплоя готового веб-решения.

### 🔗 Демонстрация и материалы
- 🌐 **Живое демо (Streamlit):** [drone-detector.streamlit.app](https://drone-detector.streamlit.app/)  
  *(💡 Примечание: после долгого неиспользования приложению требуется около 30-60 секунд на "холодный старт" и загрузку модели)*
- 📊 **Презентация работы приложения:** [Смотреть на Google Drive](https://drive.google.com/file/d/1nmS44q0gA_qWZAeCNFwawcpCUOHyju1A/view?usp=sharing)

### 🎯 Задачи
- Подготовить и конвертировать датасет для задачи детекции (формат YOLO).
- Обучить и дообучить (fine-tune) модель компьютерного зрения с оптимизацией под мелкие объекты.
- Разработать backend-ядро и REST API для инференса модели.
- Реализовать и задеплоить веб-интерфейс для демонстрации работы решения.

### 🧰 Стек технологий
Python • Ultralytics (YOLO11m) • FastAPI • Streamlit • OpenCV • Computer Vision • Git

### 📊 Данные и Метрики
- **Основной датасет:** [VisDrone Dataset](https://www.kaggle.com/datasets/kushagrapandya/visdrone-dataset) (10 209 статичных изображений, ~2.6 млн bounding boxes). Специально создан для задач компьютерного зрения с БПЛА.
- **Дополнительный датасет:** [Open Images V7](https://storage.googleapis.com/openimages/web/download_v7.html) (1.9 млн изображений). Планируется к использованию на этапе дообучения для повышения робастности модели за счет разнообразия данных.
- **Ключевая метрика оценки:** **mAP** (mean Average Precision), обеспечивающая комплексную оценку как точности (precision), так и полноты (recall) детекции.

### 🚀 Архитектура и этапы реализации MVP

**1. Подготовка данных и обучение модели:**
- Кастомный скрипт конвертации аннотаций VisDrone в формат YOLO с маппингом 7 целевых классов транспорта (`car`, `van`, `truck`, `tricycle`, `awning-tricycle`, `bus`, `motor`).
- Fine-tuning архитектуры **YOLO11m** с увеличенным размером входа (`imgsz=960`) для эффективного обнаружения мелких объектов на высоте.
- Реализация стратегии чекпоинтов и бэкапов весов (`best.pt`, `last.pt`) для устойчивого обучения в среде Colab.

**2. Создание backend-ядра:**
- Разработка скрипта инференса, который загружает лучшие веса модели и выполняет детекцию на новом изображении, возвращая кадр с отрисованными bounding boxes.
- Обертка функционала в асинхронное REST API на **FastAPI** (с использованием `python-multipart` и `pyngrok` для локального тестирования).

**3. Интерфейс и Деплой:**
- Создание интерактивного UI на **Streamlit**: загрузка файла пользователем → отправка запроса в API → визуализация обработанного изображения с рамками детекции.
- Публикация готового приложения на **Streamlit Cloud** для свободного доступа.

### 💡 Ключевые инженерные решения
- **Высокое разрешение:** Использование `imgsz=960` вместо стандартных 640 критически важно для аэрофотоснимков, где транспорт занимает малую долю пикселей кадра.
- **Модульность:** Разделение на API (FastAPI) и UI (Streamlit) позволяет в будущем легко заменять модель или масштабировать backend без переписывания интерфейса.
- **Фокус на метрике:** Оптимизация именно по mAP, а не просто по Accuracy, что является стандартом для задач object detection.
