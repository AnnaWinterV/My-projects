## Проект №5: Прогноз оттока клиентов телеком-компании

**Задачи:**
- Построение модели прогнозирования оттока клиентов.
- Анализ влияния признаков и оптимизация модели для повышения точности.

**Стек:** 
Python, Pandas, Scikit-learn, CatBoost, Optuna, Matplotlib

**Результат:**
- Проведена предобработка данных: обработаны категориальные признаки и масштабированы числовые.
- Рассмотрены разные модели: логистическая регрессия, CatBoost с базовыми и оптимизированными параметрами.
- **Лучший ROC-AUC на тесте = 0.85135** показала модель CatBoost с оптимизированными параметрами (Optuna).
- Определены ключевые признаки оттока: `MonthlySpending`, `ClientPeriod`, `NumServices`, `HasFamily`, `ServiceDensity`.
- Модель готова для практического применения в стратегии удержания клиентов.
