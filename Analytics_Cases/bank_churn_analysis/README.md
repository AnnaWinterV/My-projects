# 🏦 Прогнозирование лояльности: анализ оттока клиентов банка

**Цель проекта:** Анализ клиентской базы для выявления факторов оттока и разработка стратегий удержания.

---

## 🎯 Задачи
- Выявить ключевые факторы, влияющие на отток  
- Создать модели прогнозирования оттока  
- Разработать рекомендации для удержания клиентов

---

## 🧰 Стек технологий
Python • Pandas • Matplotlib • Yandex DataLens

---

## 📈 Результаты
- Созданы детализированные портреты клиентов (отток/лояльные)  
- Определены ключевые факторы оттока  
- Разработаны рекомендации по снижению оттока и улучшению взаимодействия с клиентами
